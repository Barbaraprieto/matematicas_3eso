Tema 2 — Funciones

1. ¿Qué es una función?

Una función es una relación entre dos magnitudes: a cada valor de la primera (variable independiente) le corresponde un único valor de la segunda (variable dependiente).

Ejemplo: “Cada número x se multiplica por 2”. f(x) = 2x

2. Representación mediante tablas

Una forma sencilla de representar una función es usando una tabla de valores.

Para f(x) = x + 3:

  • x = 1 → f(x) = 4
  • x = 2 → f(x) = 5
  • x = 3 → f(x) = 6

3. Representación gráfica

Las funciones pueden representarse en un plano cartesiano. Cada par (x, f(x)) es un punto.

f(x) = 2x → puntos: (1,2), (2,4), (3,6)

4. Funciones lineales

Son funciones cuya gráfica es una recta. Tienen la forma:

f(x) = mx + n

Elementos

  • m: pendiente (indica inclinación)
  • n: ordenada en el origen (punto donde la recta corta el eje Y)

f(x) = 3x - 1 → pendiente 3, ordenada -1

5. Interpretación de gráficas

Las gráficas permiten entender cómo cambia una magnitud respecto a otra.

  • Si la recta sube: la función es creciente.
  • Si baja: es decreciente.
  • Si es horizontal: es constante.

Una recta con pendiente positiva representa un aumento.
