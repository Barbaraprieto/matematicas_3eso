Tema 3 — Funciones y Gráficas

1. ¿Qué es una función?

Una función es una relación entre dos magnitudes: a cada valor de la variable independiente (x) le corresponde un único valor de la variable dependiente (y).

Se escribe como: y = f(x)

Ejemplo: f(x) = 2x + 3

2. Representación gráfica

Para dibujar una función:

  • Se eligen valores de x.
  • Se calculan los valores de y.
  • Se representan los puntos en el plano.
  • Se unen para formar la gráfica.

Ejemplo: f(x) = 2x + 1

  • x = 0 → y = 1
  • x = 1 → y = 3
  • x = 2 → y = 5

3. Funciones lineales

Tienen la forma: y = mx + b

  • m: pendiente (indica inclinación).
  • b: ordenada en el origen (punto donde corta el eje y).

Pendiente

Si m > 0 → la recta sube.

Si m < 0 → la recta baja.

Si m = 0 → es horizontal.

4. Funciones proporcionales

Son un caso especial de función lineal:

y = kx

  • Pasan por el origen.
  • La constante k indica la razón de proporcionalidad.

Ejemplo: precio = 5 × kilos

5. Funciones cuadráticas

Tienen la forma: y = ax² + bx + c

Su gráfica es una parábola.

  • Si a > 0 → abre hacia arriba.
  • Si a < 0 → abre hacia abajo.

Ejemplo: y = x² – 4

6. Tablas y gráficas

Para cualquier función se puede construir una tabla de valores:

Ejemplo: f(x) = x²

  • x = –2 → y = 4
  • x = –1 → y = 1
  • x = 0 → y = 0
  • x = 1 → y = 1
  • x = 2 → y = 4

La gráfica es simétrica respecto al eje y.
