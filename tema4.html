Tema 4 — Geometría Analítica

1. Sistema de coordenadas

El plano cartesiano está formado por dos ejes perpendiculares:

  • Eje X → horizontal
  • Eje Y → vertical

Un punto se representa como (x, y).

2. Representación de puntos

Para representar un punto:

  • El valor de x indica la posición horizontal.
  • El valor de y indica la posición vertical.

Ejemplo: el punto (3, 2) está 3 unidades a la derecha y 2 unidades arriba.

3. Distancia entre dos puntos

La distancia entre dos puntos A(x₁, y₁) y B(x₂, y₂) se calcula con:

d = √[(x₂ - x₁)² + (y₂ - y₁)²]

Es una aplicación directa del Teorema de Pitágoras.
