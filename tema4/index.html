Tema 6 — Geometría Analítica

1. Sistema de coordenadas

El plano cartesiano se divide en cuatro cuadrantes y cada punto se representa como (x, y).

Ejemplo: (3, -2) significa 3 unidades a la derecha y 2 hacia abajo.

2. Distancia entre dos puntos

La distancia entre dos puntos A(x₁, y₁) y B(x₂, y₂) se calcula con:

d = √[(x₂ - x₁)² + (y₂ - y₁)²]

A(1,2), B(4,6) → d = √[(4-1)² + (6-2)²] = √(9 + 16) = 5

3. Punto medio

El punto medio del segmento que une A y B es:

M = ( (x₁ + x₂)/2 , (y₁ + y₂)/2 )

A(2,4), B(6,10) → M = (4, 7)

4. Pendiente de una recta

La pendiente indica la inclinación de la recta:

m = (y₂ - y₁) / (x₂ - x₁)

Puntos (1,2) y (3,6) → m = (6-2)/(3-1) = 4/2 = 2

5. Ecuación de la recta

Forma explícita

y = mx + n

Forma general

ax + by + c = 0

Ejemplo

Pendiente 3 y punto (0, -2) → y = 3x - 2

6. Posición relativa de rectas

  • Paralelas: misma pendiente.
  • Perpendiculares: producto de pendientes = -1.
  • Coincidentes: misma ecuación.

y = 2x + 1 y y = 2x - 5 → paralelas.
