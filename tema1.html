Tema 1 — Números y Álgebra

1. Operaciones con números enteros

Los números enteros incluyen positivos, negativos y el cero. Las operaciones básicas son:

  • Suma
  • Resta
  • Multiplicación
  • División

Reglas de signos:

  • Signos iguales → resultado positivo
  • Signos distintos → resultado negativo

2. Operaciones con números racionales

Los números racionales son fracciones o decimales que pueden expresarse como fracción.

  • Suma y resta → denominador común
  • Multiplicación → numerador × numerador, denominador × denominador
  • División → multiplicar por el inverso

3. Potencias y raíces

Una potencia representa multiplicaciones repetidas.

  • an significa multiplicar a por sí mismo n veces
  • Raíz cuadrada: número que multiplicado por sí mismo da el radicando

Propiedades:

  • am · an = am+n
  • am / an = am-n
  • (am)n = am·n

4. Notación científica

Se usa para expresar números muy grandes o muy pequeños.

Formato:

  • a × 10n

donde 1 ≤ a < 10 y n es un entero.

5. Expresiones algebraicas

Una expresión algebraica combina números, letras y operaciones.

  • Término
  • Coeficiente
  • Variable
  • Grado

Se pueden simplificar agrupando términos semejantes.

6. Ecuaciones de primer grado

Una ecuación de primer grado tiene la forma:

ax + b = c

Pasos para resolver:

  • Despejar el término con x
  • Dividir entre el coeficiente

7. Sistemas sencillos de ecuaciones

Dos ecuaciones con dos incógnitas.

Métodos:

  • Sustitución
  • Igualación
  • Reducción

8. Problemas de aplicación

Se usan ecuaciones para resolver situaciones reales:

  • Edades
  • Precios
  • Velocidad, tiempo y distancia
  • Proporciones
