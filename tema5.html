Tema 5 — Estadística

1. Datos y variables

La estadística estudia conjuntos de datos para obtener información.

  • Dato: cada valor recogido.
  • Variable: característica que se estudia.

Tipos de variables:

  • Cualitativas: no numéricas (color, opinión).
  • Cuantitativas: numéricas (edad, altura).

2. Tablas de frecuencias

Se usan para organizar los datos.

  • Frecuencia absoluta (f): número de veces que aparece un dato.
  • Frecuencia acumulada (F): suma de las frecuencias hasta ese dato.
  • Frecuencia relativa (fr): f dividido entre el total.

Ejemplo:

  • Dato: 3 → f = 4
  • Dato: 5 → f = 2

3. Gráficos de barras

Representan frecuencias mediante barras verticales u horizontales.

Se usan para comparar categorías.

4. Diagramas de sectores

También llamados gráficos circulares.

Representan proporciones de un total.

Cada sector es:

(frecuencia relativa) × 360°

5. Media

La media es el promedio de los datos.

Se calcula como:

Media = (suma de los datos) / (número de datos)

Ejemplo:

Datos: 4, 6, 8 → media = (4 + 6 + 8) / 3 = 6

6. Mediana

La mediana es el dato central cuando los datos están ordenados.

  • Si hay número impar de datos → el central.
  • Si hay número par → promedio de los dos centrales.

7. Moda

La moda es el dato que más se repite.

Puede haber:

  • Una moda (un dato más repetido).
  • Varias modas (dos o más datos repetidos igual).
  • Sin moda (ningún dato se repite).

8. Interpretación de datos

Consiste en analizar los resultados para sacar conclusiones.

  • Comparar medias.
  • Ver tendencias.
  • Detectar valores extremos.
