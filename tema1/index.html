Tema 1 — Números y Operaciones

1. Conjuntos numéricos

En 3º ESO trabajamos con varios tipos de números:

  • Naturales (N): 1, 2, 3, 4…
  • Enteros (Z): … -3, -2, -1, 0, 1, 2…
  • Racionales (Q): fracciones y decimales exactos o periódicos.
  • Irracionales (I): decimales infinitos no periódicos (π, √2…).
  • Reales (R): todos los anteriores.

2. Operaciones con enteros

Reglas básicas:

  • Suma y resta: signos iguales → se suman; signos distintos → se restan.
  • Multiplicación:
    • (+) × (+) = (+)
    • (+) × (–) = (–)
    • (–) × (+) = (–)
    • (–) × (–) = (+)
  • División: mismas reglas de signos que la multiplicación.

3. Fracciones

Conceptos clave:

  • Simplificar: dividir numerador y denominador por el mismo número.
  • Fracciones equivalentes: representan el mismo valor.
  • Suma y resta:
    • Mismo denominador → se suman/restan numeradores.
    • Diferente denominador → se busca común denominador.
  • Multiplicación: numerador × numerador, denominador × denominador.
  • División: multiplicar por la inversa.

4. Potencias

Una potencia tiene la forma aⁿ, donde:

  • a es la base.
  • n es el exponente.

Propiedades

  • aⁿ · aᵐ = aⁿ⁺ᵐ
  • aⁿ / aᵐ = aⁿ⁻ᵐ
  • (a · b)ⁿ = aⁿ · bⁿ
  • (aⁿ)ᵐ = aⁿᵐ
  • a⁰ = 1

5. Notación científica

Se usa para escribir números muy grandes o muy pequeños.

Forma: a × 10ⁿ, donde 1 ≤ a < 10.

Ejemplos:

  • 3500000 = 3,5 × 10⁶
  • 0,00042 = 4,2 × 10⁻⁴
