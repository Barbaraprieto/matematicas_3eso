Tema 4 — Estadística

1. ¿Qué es la estadística?

La estadística estudia cómo recoger, organizar y analizar datos para obtener conclusiones.

2. Tablas de datos

Los datos pueden organizarse en tablas para facilitar su interpretación.

Ejemplo: número de libros leídos por 5 alumnos.

  • Ana: 3
  • Juan: 5
  • Lucía: 2
  • Pedro: 4
  • María: 6

3. Gráficos

Los gráficos permiten visualizar los datos de forma clara.

Tipos de gráficos

  • Gráfico de barras: compara cantidades.
  • Diagrama de sectores: muestra proporciones.
  • Histograma: agrupa datos en intervalos.

Un gráfico de barras puede mostrar cuántos libros leyó cada alumno.

4. Medidas de centralización

Media

Es el promedio de los datos.

Media = (3 + 5 + 2 + 4 + 6) / 5 = 4

Mediana

Es el valor central cuando los datos están ordenados.

Datos ordenados: 2, 3, 4, 5, 6 → mediana = 4

Moda

Es el valor que más se repite.

Si los datos fueran 3, 3, 4, 5, 6 → moda = 3

5. Medidas de dispersión

Rango

Diferencia entre el mayor y el menor valor.

Rango = 6 - 2 = 4

6. Interpretación de datos

La estadística permite responder preguntas como:

  • ¿Cuál es el valor más frecuente?
  • ¿Cuál es el promedio?
  • ¿Cómo se distribuyen los datos?

Si la media es alta, los alumnos han leído muchos libros.
